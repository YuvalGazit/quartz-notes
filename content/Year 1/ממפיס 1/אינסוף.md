# אינסוף - infinity
$$\lim_{ x \to x_{0} }f(x)=\infty$$
- ככל שנתקרב לx0, ערך הפונקצייה יהיה גדול כרצוננו (גדול יותר מכל מספר חיובי שנבחר)
- כנל למינוס אינסוף
- לדוגמא הפונקצייה $f(x)= \frac{1}{x}$
![[1 חלקי X|center|200]]
$$\lim_{ x \to 0^+ } \frac{1}{x}=+\infty$$
- המשתנה הב"ת (בלתי תלוי, X) יכול גם לשאוף לאינסוף
$$\lim_{ x \to \infty } \frac{1}{x} = 0$$
