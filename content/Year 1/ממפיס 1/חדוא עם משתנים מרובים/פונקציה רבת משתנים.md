## גבול
- [[גבול]] "קיים" אם ערך הגבול אינו תלוי במסלול $(x,y)$ דרכו שואפת ל$(x_{0},y_{0})$. $$
\lim_{ \begin{matrix}
x \to x_{0} \\
y \to y_{0}
\end{matrix} } f(x,y)=A
$$
## רציפות
זהה ל[[פונקציה#רציפות של פונקצייה]] רגילה. נגיד ש$f(x,y)$ רציפה ב$(x_{0},y_{0})$ אם 
$$
\lim_{ (x,y) \to (x_{0},y_{0}) } f(x,y)=f(x_{0},y_{0})
$$
עכשיו זה יהיה מוגדר באיזור, לא בתחום (כי זה שטח, לא חלק מקו)
## נגזרת
[[נגזרת|גזירה]] של פ' רבת משתנים לפי אחד המשתנים הבלתי תלויים כאשר מתיחסים לשאר כקבועים.
$$
\frac{ \partial f }{ \partial x } \equiv \lim_{ \Delta x \to 0 } \frac{f(x+\Delta x,y)-f(x,y)}{\Delta x}
$$
$$
\frac{ \partial f }{ \partial y } \equiv \lim_{ \Delta y \to 0 } \frac{f(x,y+\Delta y)-f(x,y)}{\Delta y}
$$
לפעמים מסמנים $\frac{ \partial f }{ \partial x }=f_{x}=\frac{ \partial f }{ \partial x }|_{y}$
למשל:
$$
\begin{matrix} 
 & f(x,y,z)=xy+yz+xz  \\
\frac{ \partial f }{ \partial x } = y+z & 
f_{y}=x+z  & 
f_{z}=y+x
\end{matrix}
$$

## נגזרות גבוהות
[[נגזרת גבוהה]] תסומן כך:
$$
\frac{ \partial  }{ \partial x } \left( \frac{ \partial f }{ \partial x }  \right)=\frac{ \partial^{2}f }{ \partial x^{2} } =f_{xx}
$$
$$
\frac{ \partial  }{ \partial y } \left( \frac{ \partial f }{ \partial x }  \right)=\frac{ \partial^{2}f }{ \partial y \partial x } =f_{yx}
$$
אם $f_{yx},f_{xy}$ רציפות, אז $f_{xy}=f_{yx}$, כלומר סדר הגזירה לא משנה.
## דיפרנציאל
ה[[דיפרנציאל]] השלם של f
`perfect diffrential`
$$
df=\lim_{ \begin{matrix}
\Delta x \to 0 \\
\Delta y \to 0
\end{matrix} }\Delta f=\frac{ \partial f }{ \partial x }  dx+\frac{ \partial f }{ \partial y } dy
$$
## כלל השרשרת
איך נראה [[כלל השרשרת]] בפונקציות כאלה?
$$
\begin{matrix}
 & z=z(x,y) \\
y=y(r,s) &  & x=x(r,s)
\end{matrix}
$$
נכתוב את כל ה[[#דיפרנציאל|דיפרנציאלים השלמים]] שאנחנו יכולים
$$
\begin{matrix} 
dz=\frac{ \partial z }{ \partial x } \textcolor{ red}{dx} +\frac{ \partial z }{ \partial y } \textcolor{ green}{dy}  \\
dz=\frac{ \partial z }{ \partial r } dr+\frac{ \partial z }{ \partial s } ds \\
\textcolor{ red}{dx} =\frac{ \partial x }{ \partial r } dr+\frac{ \partial x }{ \partial s } ds \\
\textcolor{ green}{dy}=\frac{ \partial y }{ \partial r } dr+\frac{ \partial y }{ \partial s } ds
\end{matrix}
$$
נציב ונפתח, ונקבל:
$$
\boxed{ \frac{ \partial z }{ \partial r } = \frac{ \partial z }{ \partial x } \frac{ \partial x }{ \partial r } +\frac{ \partial z }{ \partial y } \frac{ \partial y }{ \partial r } 
 }$$
$$
\boxed{ \frac{ \partial z }{ \partial s } = \frac{ \partial z }{ \partial x } \frac{ \partial x }{ \partial s } +\frac{ \partial z }{ \partial y } \frac{ \partial y }{ \partial s } 
 }$$
## נקודות קיצון
בשביל למצוא [[נקודת קיצון]], לא מספיק איפוס כל הנגזרות, אלא צריך את התנאי הבא:
$$
\Delta=f_{xx}f_{yy}-f_{xy}^{2}>0
$$
כדי למצוא את סוג הנקודת קיצון, מספיק לבדוק הנגזרת שנייה של רק מאחד המשתנים.
אם $\Delta < 0$, זה נקרא [[נקודת אוכף]].
