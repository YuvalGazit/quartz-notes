[[פונקציה]] אשר כתובה בצורה שלא מגדירה מה המשתנה התלוי ומה הבלתי תלוי.
$$
f(x,y)=0 \,\, \begin{cases}
x=x(y) \\
y=y(x)
\end{cases}
$$
## גזירה
[[נגזרת|גזירה]] של פונקציה סתומה - נבחר שרירותית את אחד המשתנים להיות התלוי, ואז נשתמש ב[[פונקציה רבת משתנים#כלל השרשרת|כלל השרשרת של רבת משתנים]].
$$
\begin{matrix}
f(x,y)=0 \implies f(x,y(x))=0 \\
\frac{ \partial f }{ \partial x } \frac{dx}{dx}+\frac{ \partial f }{ \partial y } \frac{dy}{dx}=0
\end{matrix}
$$
$$
\frac{dy}{dx}=- \frac{\frac{ \partial f }{ \partial x } }{\frac{ \partial f }{ \partial y } }
$$

עם שלוש משתנים - $f(x,y,z)=0 \implies z(x,y)$, ונגזור לפי x
במקרה הזה, מכיוון שy וx אינם תלויים, $\frac{ \partial y }{ \partial x }$ שווה לאפס!
$$
\frac{ \partial z }{ \partial x } =- \frac{\frac{ \partial f }{ \partial x } }{\frac{ \partial f }{ \partial z } }
$$
