## a. 
$$
\lim_{ x \to 1 } \frac{x-1}{x^{2}-1}=\lim_{ x \to 1 } \frac{x-1}{(x-1)(x+1)}=\lim_{ x \to 1 } \frac{1}{x+1}= \frac{1}{2} 
$$
כאשר בפונקציה $x\neq1$

## b.
$$

$$
## c. 
$$
\lim_{ x \to 0 } \frac{\sqrt{ x +1}-1}{x}=\lim_{ x \to 0 } \frac{\sqrt{ x +1}-1}{(\sqrt{ x +1}-1)(\sqrt{ x +1}+1)}=\lim_{ x \to 0 } \frac{1}{\sqrt{ x +1}+1}=\frac{1}{2}
$$

## א
בעזרת הגבול הניתן, נוכיח:
$$
\lim_{ x \to 0 } \frac{\sin ax}{x}=\lim_{ x \to 0 } a* \frac{\sin ax}{ax}=a* \lim_{ x \to 0 } \frac{\sin ax}{ax}=a*1=a
$$
עם זה, נמשיך:
$$
\lim_{ x \to 0 } \frac{\cos ^{2}ax-\cos ^{2}bx}{x^{2}}
=\lim_{ x \to 0 } \frac{1-\sin ^{2}ax-1+\sin ^{2}bx}{x^{2}}
$$
$$
=\lim_{ x \to 0 } \left( \frac{\sin bx}{x} \right)^{2}-\lim_{ x \to 0 } \left( \frac{\sin ax}{x} \right)^{2}
=b^{2}-a^{2}
$$

### i
בדומה לסעיף הקודם, בעזרת הגבול הניתן, נוכיח:
$$
\lim_{ x \to 0 } \frac{e^{ax}-1}{x}=a*\lim_{ x \to 0 } \frac{e^{ax}-1}{ax}=a
$$
ואז נמשיך:
$$
\lim_{ x \to 0 } \frac{e^{-ax}-e^{-bx}}{x}=\lim_{ x \to 0 } \frac{e^{-ax}}{x}-\lim_{ x \to 0 } \frac{e^{-bx}}{x}=b-a
$$
### ii
$$
\lim_{ x \to 0 } \frac{a^x-b^x}{x}
=\lim_{ x \to 0 } \frac{e^{x\ln a}-e^{x\ln b}}{x}
=\lim_{ x \to 0 } e^{x\ln b} \frac{e^{x(\ln a-\ln b)}-1}{x}
$$
$$
=\lim_{ x \to 0 } e^{x\ln b}*\lim_{ x \to 0 } \frac{e^{x(\ln a-\ln b)}-1}{x}
=1*(\ln a-\ln b)=\ln\left( \frac{a}{b} \right)
$$

# 6
$$
\left[ \frac{f(x)}{g(x)} \right]'
=\lim_{ \Delta x \to 0 } \frac{\frac{f(x+\Delta x)}{g(x+\Delta x)}-\frac{f(x)}{g(x)}}{\Delta x}
=\lim_{ \Delta x \to 0 } \frac{\frac{f(x+\Delta x)g(x)-f(x)g(x+\Delta x)}{g(x+\Delta x)g(x)}}{\Delta x}
$$
$$
=\lim_{ \Delta x \to 0 } \frac{f(x+\Delta x)g(x)-f(x)g(x+\Delta x)}{g(x+\Delta x)g(x)\Delta x}
$$
$$
=\lim_{ \Delta x \to 0 } \frac{f(x+\Delta x)g(x)+f(x)g(x)-f(x)g(x)-f(x)g(x+\Delta x)}{g(x+\Delta x)g(x)\Delta x}
$$
$$
=\lim_{ \Delta x \to 0 } \frac{g(x)[f(x+\Delta x)-f(x)]-f(x)[g(x+\Delta x)-g(x)]}{g(x+\Delta x)g(x)\Delta x}
$$
$$
=\lim_{ \Delta x \to 0 } \frac{g(x)[f(x+\Delta x)-f(x)]}{g(x+\Delta x)g(x)\Delta x}-\frac{f(x)[g(x+\Delta x)-g(x)]}{g(x+\Delta x)g(x)\Delta x}
$$
$$
=\lim_{ \Delta x \to 0 } \frac{1}{g(x+\Delta x)g(x)}*[g(x)f'(x)-g'(x)f(x)]
$$
$$
=\frac{g(x)f'(x)-g'(x)f(x)}{g(x)^{2}}
$$

# 7
$$
\lim_{ \Delta x \to 0 } \frac{\ln(x+\Delta x)-\ln x}{\Delta x}
=\lim_{ \Delta x \to 0 } \frac{\ln\left( \frac{x+\Delta x}{x} \right)}{\Delta x}
=\lim_{ \Delta x \to 0 } \frac{\ln\left( 1+\frac{\Delta x}{x} \right)}{\Delta x}
$$
נגדיר $z=\frac{\Delta x}{x}$
$$
=\lim_{ z \to 0 } \frac{\ln(1+z)}{zx}
=\frac{1}{x}\left[ \lim_{ z \to 0 } \frac{\ln(1+z)}{z} \right] \to
$$
בעזרת המשפטים הניתנים, נוכיח:
$$
\begin{matrix}
\lim_{ z \to 0 } (1+z)^{\frac{1}{z}}=e \\
\lim_{ z \to 0 } \ln (1+z)^{\frac{1}{z}}=\ln e \\
\lim_{ z \to 0 } \frac{\ln(1+z)}{z}=1
\end{matrix}
$$
ועם זה:
$$
\to=\frac{1}{x}\left[ \lim_{ z \to 0 } \frac{\ln(1+z)}{z} \right]=\frac{1}{x}
$$

## a.
$$
f(x)=\sqrt{ x^{2}-a^{2} }=\sqrt{ (x-a)(x+a) }
$$
$$
f'(x)=\frac{\sqrt{ x+a }}{2\sqrt{ x-a }}+\frac{\sqrt{ x-a }}{2\sqrt{ x+a }}
=\frac{x+a+x-a}{2\sqrt{ x^{2}-a^{2} }}
=\frac{x}{\sqrt{ x^{2}-a^{2} }}
$$
## b.
$$
f(x)=\frac{1+\sqrt{ x }}{1-\sqrt{ x }}
$$
$$
f'(x)=\frac{\frac{1}{2\sqrt{ x }}(1-\sqrt{ x })-\frac{1}{-2\sqrt{ x }}(1+\sqrt{ x })}{(1-\sqrt{ x })^{2}}
=\frac{\frac{1-\sqrt{ x }+1+\sqrt{ x }}{2\sqrt{ x }}}{1-2\sqrt{ x }+x}
=\frac{\frac{1}{\sqrt{ x }}}{1-2\sqrt{ x }+x}
$$
$$
=\frac{1}{\sqrt{ x }-2x+x\sqrt{ x }}
=\frac{1}{\sqrt{ x }+x(\sqrt{ x }-2)}
$$
## c.
$$
f(x)=\frac{x}{x^{2}-x-2}=\frac{x}{(x-2)(x+1)}
$$
$$
f'(x)=\frac{(x-2)(x+1)-x(2x-1)}{(x-2)^{2}(x+1)^{2}}
=\frac{-x^{2}-2}{(x-2)^{2}(x+1)^{2}}
